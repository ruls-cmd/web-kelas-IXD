FOTO KELAS IXD

Foto siswa sudah disesuaikan dengan nomor absen dan nama file yang dipakai oleh script.js:

01 -> siswa01.jpg
02 -> siswa02.jpg
...
25 -> siswa25.jpg

Letakkan folder "foto" ini di dalam folder project yang sama dengan:
- index.html
- style.css
- script.js

Struktur:
IXD-Yearbook/
├── index.html
├── style.css
├── script.js
└── foto/
    ├── siswa01.jpg
    ├── siswa02.jpg
    ├── ...
    └── siswa25.jpg
